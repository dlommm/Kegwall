# Admin dashboard and mobile navigation

The dashboard brings today's pour totals, active taps, temperature readings, and source status
together above the tap list. Temperature probes share one summary card, including humidity and
warming notices where available. The activity card shows the five latest events; open **Logs**
for the full history or **Pours** to assign an unclaimed pour. Taps whose line-cleaning reminders
are ignored are listed in a short note below **Needs attention** (see
[Cleaning reminders and unclaimed pours](cleaning-and-pours.md)).

Every admin page shows its own title at the top of the content, and the browser tab is named after
the current section (for example "Pours · Kegwall"), so several open admin tabs stay easy to tell
apart.

On narrow screens, use **Menu** in the top-left to open the section list and account controls.
The menu closes when you choose a section, press **Escape**, or navigate any other way (a dashboard
link, the browser's back button). Quick navigation search is hidden on small screens because the
menu provides direct access to each section; it remains available in the desktop top bar
(**⌘K** / **Ctrl+K**).
